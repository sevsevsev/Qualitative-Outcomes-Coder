## Caveats

- **Both coders are Claude models.** High agreement can reflect shared blind spots.
  Human adjudication is the anchor.
- **The held-out set is now used up for rc1.** It helped shape the rc1 fixes, so it
  can't fairly test them. PLAN.md phase 2 needs a fresh one.
- **Research in this cycle was not blind.** It was done by the orchestrator, not the
  independent verifier. All 16 `located` sources, and the 11 `verified` ones, go
  through `codebook-citation-verifier` in phase 1.
- **The v2 schema hasn't been tested live.** Estimated footprint is about 151 enum
  values, against 142 known to work (PLAN.md phase 3).
