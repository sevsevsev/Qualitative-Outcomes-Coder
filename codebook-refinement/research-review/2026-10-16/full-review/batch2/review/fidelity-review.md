# Batch 2 (Y5, Y6, Y7): framework-fidelity review (2026-10-16)

Reviewer: fidelity (S1.6, S4.1, S4.9). I did not do the research, and I did not read the held-out
gold. Sources missing from the verification table (Catalano's resilience, Peterson & Seligman,
Conley's work side, Lerner, Shogren, Carlone & Johnson) are leads only.

## Two rules I applied

1. **Which way a partial fit runs.** If the *source* is broader and contains the code's element,
   it is not a departure. If the *code* names something the source does not, it is. The
   researchers counted both kinds, which overstates Y5 and Y6.
2. **Several verified components in one code are not a merged-components FD.** Y5.4 cites two
   CASEL bullets and a Search asset as `framework` with no FD. Merged-components is for components
   coders *cannot tell apart*; faith growth (S016) and optimism are easy to tell apart.

## Decision C (age rule): where it matters

As an **age** rule, C removes FDs for: Search assets (12-18) in Y5.4-Y5.6, Y6.1, Y6.4, Y6.5;
CIRCLE (15+) in Y6.4-Y6.5; WIOA youth (14-24) and Perkins (middle grades up) in Y7.1-Y7.5; Casey
(14-21) for Y7.7 "self-care at camp" (S162). Without C, Y6 alone would cross a third.

**Read literally**, C also removes FDs for **sector**-specific sources: Chafee and 675(5)(I)
(foster care), 733 (disability), FS221 in Y1. Y7.7's text never names foster care, so FD-P15
would never have been needed, and S1.6's sector-widening case would be nearly empty. **Severin
should limit C to age bands within youth.** I apply that reading.
