# Youth-development panelist: notes on CP-12-33 rows (questions 2 and 3)

1. **P-F24-10 (hygiene): the intended side is defensible, but the prompt is too loose.** Practitioners file hygiene kits next to period products, so the coders' F2.4 is the natural reading. Nothing in the prompt excludes hygiene, and CF-037 is not in the prompt. The current DOMAIN ONLY bullet covers only text that names "no specific result", so it does not reach a named good that has no code. Smallest fix: add "general hygiene items (soap, deodorant, toothpaste)" to F2.4 Exclude, and to Use instead as "Domain F2, subcategory none". This also depends on CP-12-19's G9 bullet being in the prompt. Without both, keep the row out of scoring. Severin should expect this row to come back often, because hygiene kits are among the most common donated goods.
2. **P-F24-25 (dignity): the coders are right, so change the row to Y5.4.** "Children will feel dignity" puts a felt self-worth in the child, and Y5.4 is titled "Self-Worth". Rule 2's "the goods are the means" logic then sends it to Y5.4. Practitioners use "dignity" in two ways. The first is the manner of service ("families shop with dignity", "receive clothing with dignity"), which is not a child's result. The second is the child's own feeling ("feel dignity", "feel respected"), which is self-worth. Reword CF-037's last bullet: "dignity" describing how goods are given names no Y5 result, so code the goods (A2.3 or F2.4); a young person who feels dignity, pride or self-respect gets Y5.4.
3. **Rule 2's example repeats P-F24-01, and that matters a little.** It breaks no rule, since these are invented design rows and not held-out. But a row whose answer is printed in the prompt tests recall, not the boundary. "students will receive school supplies" does the same for P-F24-02. Change the examples to other goods (for example "500 backpacks handed out", "players will receive cleats"), or reword P-F24-01 and P-F24-02.
4. **The A2.3 Use instead pointer is narrower than its own Exclude.** The pointer names only "clothing or supplies", but the Exclude names clothing, shoes, gear, school supplies and menstrual materials. Make the pointer match the Exclude.
5. **P-F24-18:** Y2.6's Include "participating fully alongside peers" pulls class participation toward Y2.6. Add "class participation -> Y1.9" to Y2.6's Use instead, or add a CF-037 bullet (it already lists Y1.9).
6. **F2.4's "for lack of money" clause:** practitioners almost never state why a child lacks an item. Add "the cause need not be stated" so coders do not hold back F2.4 on that clause.
