## Missed issues

1. **Unit of count versus construct.** Coders route a count of credentialed people differently from one person's credential (P-33). The codebook should state that a code follows the construct, never whether it is counted individually or in aggregate. The same applies to A1.1/A1.3, Y7.4 and Y1.18.
2. **Y7.4's live name and include do not mention entrepreneurship.** The edge list and rows P-11 and P-12 assume they do. Those rows should be marked conditional, or wait until the deferred include (20 CFR 681.560, PARTIAL) lands. Otherwise gold will contradict the live prompt.
3. **Justice-system statements about families need Part routing.** Truancy-court diversion targets parents, and Y8.13 is youth-only. Add a general line: a justice or child-welfare system result for the family → F1 domain-only.
4. **Compound statements make poor boundary gold.** P-23 and P-73 each hold two or three results. Swap in single-outcome statements before adjudication so the rows test one boundary.
5. **Domain-only frequency should feed the code backlog.** With G9, school climate, volunteer outcomes, community health, audiences and partner satisfaction all pile up as domain-only with the gap flag. Report gap-flag counts per domain on the dashboard, and set a frequency threshold (unique texts across programs) that triggers a new-code review.
